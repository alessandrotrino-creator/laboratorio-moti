# Laboratorio dei Moti

Simulatore e eserciziario di cinematica per la scuola secondaria di primo grado. Un solo file
(`index.html`): si apre con un doppio clic o si pubblica con GitHub Pages.

## Che cosa contiene
- **Laboratorio**: moto rettilineo uniforme, uniformemente accelerato, circolare uniforme, armonico (molla,
  pendolo, altalena), **due corpi** (incontro e inseguimento, anche con partenza ritardata o accelerazione) e
  **moti composti** (barca nel fiume, tapis roulant, lancio orizzontale, lancio obliquo).
  Si scrivono i dati che si conoscono e il laboratorio ricava gli altri mostrando formule e passaggi.
  Animazione con auto, treno, bici, razzo, corridore…, grafici spazio–tempo, velocità–tempo e
  accelerazione–tempo, foto a intervalli, vettori.
- **Esercizi**: tre livelli, serie da 10 con autocorrezione, suggerimenti, soluzione passo passo, molti
  tipi diversi per livello con numeri sempre nuovi.
- **Formule**: tutte le formule dirette e inverse, i grafici tipici e le conversioni, da stampare.
